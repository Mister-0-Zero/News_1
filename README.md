# Шаблон корпоративной новости

Статическая страница без сборки и зависимостей. Основной контент меняется в `content.json`, внешний вид — в `styles.css`, структура — в `index.html`.

Запуск из папки проекта: `python -m http.server 8000`, затем http://localhost:8000. Двойной клик по HTML не подходит для загрузки JSON.

Изображения и презентации поместите в `assets/`, слайды — в `assets/slides/`. Указывайте относительные пути в content.json. Пустые поля изображений и презентации скрывают соответствующие элементы. Не оставляйте ссылки на отсутствующие файлы. Дополнительные фотографии сотрудников можно встроить в HTML после их получения.

GitHub: https://github.com/Mister-0-Zero/News_1 . Текущая ветка при подготовке шаблона: master. Публикация через GitHub Pages из корня выбранной ветки; фактические настройки необходимо проверить в репозитории.

Задание следующему агенту находится в MODEL_PROMPT.md. Старые материалы сохранены вне репозитория в News_1-backup-20261014.zip в папке Работа. Шаблон не содержит изображений и заполненной новости.
